### 清风年付、乘风月付和不限时流量包有什么区别？

清风需一次支付 **¥137/年**，每月提供 **100GB**；乘风可按 **¥27/月**购买，每月提供 **200GB**。信风与长风分别一次支付 **¥200、¥370**，获得 **270GB、570GB** 总流量，用完为止。比较时应分别核对付款周期、每月流量和一次性总流量。

<a id="breeze-device-and-traffic-rules"></a>

### 不限速、不限制设备是否等于不限流量？

不限速与不限制设备同时接入描述的是速度和连接设备规则，仍需按照套餐额度使用流量。周期套餐有每月额度，不限时套餐则消耗固定总流量。

<a id="breeze-client-support"></a>

微风网络支持通用订阅，服务资料列有 Shadowsocks、VMess 与 Trojan 协议，可选择支持对应协议的 Windows、macOS、iOS、Android 客户端。安装与导入可参考[客户端教程汇总](https://eoht.net/serve/antiwall/summary)，具体订阅格式以服务方提供的配置为准。
